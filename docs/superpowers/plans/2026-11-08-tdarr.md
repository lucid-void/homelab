# Tdarr library transcoding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy Tdarr so H.264 1080p episodes and movies are re-encoded to HEVC on llm-1, with every output verified before it replaces an original that is kept in a 14-day trash.

**Architecture:** A Tdarr server (UI, queue, library scanning) in `media`, plus one mapped Tdarr node pinned to llm-1 that does the x265 encodes. The node mounts `media-nfs` read-write and ships a verify-then-swap shell script (via ConfigMap) that a Tdarr flow calls after each encode. A daily CronJob purges the trash. Libraries and flows are Tdarr runtime state (UI), so they are documented, not GitOps.

**Tech Stack:** Flux + Kustomize, bjw-s `app-template` 3.7.3, `ghcr.io/haveagitgat/tdarr` + `tdarr_node`, POSIX sh, ffmpeg/ffprobe, VictoriaMetrics (VMRule, VMServiceScrape), `homeylab/tdarr-exporter`.

**Spec:** `docs/superpowers/specs/2026-11-07-tdarr-design.md`

## Global Constraints

- Never write a raw `Secret`. Seal it with `mise exec -- kubeseal --cert kubernetes/flux/pub-cert.pem --format yaml`. (This plan needs none.)
- Never use `Ingress`. Use `HTTPRoute` with `parentRefs: [{name: shared, namespace: gateway}]`.
- Never `kubectl apply` a config change. It goes through git and Flux. `kubectl exec`/`get`/`logs` is for diagnostics only.
- Never set `spec.targetNamespace` on a Kustomization whose resources span namespaces. Task 5 spans `media` and `monitoring`, so it gets its own Kustomization with no `targetNamespace`.
- Never use a rolling image tag (`latest`, `3`). Pin the full tag.
- Never `apk add` in a Job or initContainer.
- Never trust `optional: true` on an app-template `envFrom`.
- Never assume a Helm values path took effect. Render or check the live object.
- Never size a workload from Goldilocks/VPA.
- After editing any manifest, run `.agents/scripts/validate-manifests.sh <file>` per file. A directory argument checks nothing.
- All k8s tools run as `mise exec -- kubectl|flux|...`.
- Media-stack identity: `PUID=2202`, `PGID=2200`. The `Media` share root is `/Media` inside pods.
- Libraries are `Series/`, `Series_done/`, `Movies/` only. Trash is `/Media/.tdarr-trash`, outside all three.
- Encode: x265 `slow`, CRF about 21, 10-bit, mkv. Audio and all subtitle streams copied unchanged.
- Server and node both mount `media-nfs` read-write, like sonarr.
- Node resources: CPU request `500m`, limit `6`. Node runs on llm-1 and tolerates `workload=llm:NoSchedule`.
- Verify rules: output codec HEVC, duration within 1 s, same audio and subtitle stream counts and languages, zero decode errors, output smaller than the source.
- Trash retention 14 days. Rollout order: test, pilot (about 100 files), full run, with approval between phases.

## Review Focus

1. **mp4 source with an mkv already beside it.** The output is `x.mkv`; if `x.mkv` already exists the swap must refuse and leave everything alone.
2. **Output on a different filesystem than the destination.** `mv` would silently become a long copy. The swap must refuse.
3. **Trashed original keeps its old mtime.** A 14-day purge by mtime would delete it at once unless the swap touches it.
4. **Output that probes fine but is corrupt mid-stream.** Only the full decode pass catches it.
5. **File names with spaces, quotes, `$`, or a leading `-`.** The script must quote everything and survive them.

- [ ] **Step 2: Write the failing test**

`kubernetes/apps/media/tdarr/tests/tdarr-swap.test.sh`:

```sh
#!/bin/sh
# Run inside the node pod, never against the live library:
#   kubectl exec -i -n media deploy/tdarr-node -- sh -s < kubernetes/apps/media/tdarr/tests/tdarr-swap.test.sh
set -u
SWAP=/scripts/tdarr-swap.sh
FFMPEG="${FFMPEG:-ffmpeg}"
export MEDIA_ROOT=/Media/.tdarr-test
export TRASH_DIR="$MEDIA_ROOT/.trash"
T="$MEDIA_ROOT/run-$$"
mkdir -p "$T" "$TRASH_DIR"
fail=0

ok()   { echo "ok   - $1"; }
bad()  { echo "FAIL - $1"; fail=1; }
check() { # check <name> <command...>
  n=$1; shift
  if "$@"; then ok "$n"; else bad "$n"; fi
}
exit_is() { # exit_is <name> <want> <command...>
  n=$1; w=$2; shift 2
  "$@" >/dev/null 2>&1; g=$?
  if [ "$g" -eq "$w" ]; then ok "$n"; else bad "$n (want $w, got $g)"; fi
}

mksrc() { # mksrc <file> : 6 s h264 + aac + 1 srt-less audio, large enough that hevc is smaller
  "$FFMPEG" -v error -y -f lavfi -i testsrc=d=6:s=640x360:r=24 -f lavfi -i sine=d=6 \
    -c:v libx264 -crf 12 -c:a aac "$1"
}
mkout() { # mkout <src> <out> [extra ffmpeg args...]
  s=$1; o=$2; shift 2
  "$FFMPEG" -v error -y -i "$s" -c:v libx265 -crf 30 -c:a copy "$@" "$o"
}

# 1. pass: mkv -> mkv, same name, original lands in trash with a fresh mtime
mksrc "$T/a.mkv"; mkout "$T/a.mkv" "$T/a.out.mkv"
touch -d '2020-01-01' "$T/a.mkv"
exit_is "pass mkv exits 0" 0 sh "$SWAP" "$T/a.mkv" "$T/a.out.mkv"
check "pass: new file at original path is hevc" sh -c "ffprobe -v error -select_streams v:0 -show_entries stream=codec_name -of csv=p=0 '$T/a.mkv' | grep -qx hevc"
check "pass: original is in trash" test -f "$TRASH_DIR/run-$$/a.mkv"
check "pass: trashed original mtime was refreshed (review focus 3)" test -z "$(find "$TRASH_DIR/run-$$/a.mkv" -mtime +1)"

# 2. pass: mp4 -> mkv changes the extension
mksrc "$T/b.mp4"; mkout "$T/b.mp4" "$T/b.out.mkv"
exit_is "pass mp4 exits 0" 0 sh "$SWAP" "$T/b.mp4" "$T/b.out.mkv"
check "mp4: result is b.mkv" test -f "$T/b.mkv"
check "mp4: b.mp4 is gone from the library path" test ! -e "$T/b.mp4"
check "mp4: original b.mp4 is in trash" test -f "$TRASH_DIR/run-$$/b.mp4"

# 3. refuse: mp4 with an mkv already beside it (review focus 1)
mksrc "$T/c.mp4"; mkout "$T/c.mp4" "$T/c.out.mkv"; cp "$T/c.out.mkv" "$T/c.mkv"
exit_is "collision exits 20" 20 sh "$SWAP" "$T/c.mp4" "$T/c.out.mkv"
check "collision: c.mp4 untouched" test -f "$T/c.mp4"
check "collision: existing c.mkv untouched" cmp -s "$T/c.mkv" "$T/c.out.mkv"

# 4. reject: output still h264
mksrc "$T/d.mkv"; "$FFMPEG" -v error -y -i "$T/d.mkv" -c:v libx264 -crf 30 -c:a copy "$T/d.out.mkv"
exit_is "h264 output exits 10" 10 sh "$SWAP" "$T/d.mkv" "$T/d.out.mkv"
check "h264: original untouched" test -f "$T/d.mkv"

# 5. reject: duration short by 3 s
mksrc "$T/e.mkv"; mkout "$T/e.mkv" "$T/e.out.mkv" -t 3
exit_is "short output exits 10" 10 sh "$SWAP" "$T/e.mkv" "$T/e.out.mkv"

# 6. reject: audio dropped
mksrc "$T/f.mkv"; mkout "$T/f.mkv" "$T/f.out.mkv" -an
exit_is "missing audio exits 10" 10 sh "$SWAP" "$T/f.mkv" "$T/f.out.mkv"

# 7. reject: probes fine but corrupt mid-stream (review focus 4)
mksrc "$T/g.mkv"; mkout "$T/g.mkv" "$T/g.out.mkv"
sz=$(stat -c %s "$T/g.out.mkv")
dd if=/dev/urandom of="$T/g.out.mkv" bs=1 seek=$((sz / 2)) count=4096 conv=notrunc 2>/dev/null
exit_is "corrupt output exits 10" 10 sh "$SWAP" "$T/g.mkv" "$T/g.out.mkv"
check "corrupt: original untouched" test -f "$T/g.mkv"

# 8. reject: output larger than the source
mksrc "$T/h.mkv"; mkout "$T/h.mkv" "$T/h.out.mkv" -crf 0
"$FFMPEG" -v error -y -i "$T/h.mkv" -c:v libx265 -crf 0 -c:a copy "$T/h.out.mkv"
exit_is "larger output exits 10" 10 sh "$SWAP" "$T/h.mkv" "$T/h.out.mkv"

# 9. reject: zero-byte output
mksrc "$T/i.mkv"; : > "$T/i.out.mkv"
exit_is "empty output exits 10" 10 sh "$SWAP" "$T/i.mkv" "$T/i.out.mkv"

# 10. awkward names survive (review focus 5)
D="$T/it's a \$dir"; mkdir -p "$D"
mksrc "$D/-weird name \"1\".mkv"; mkout "$D/-weird name \"1\".mkv" "$D/out file.mkv"
exit_is "awkward names exit 0" 0 sh "$SWAP" "$D/-weird name \"1\".mkv" "$D/out file.mkv"

# 11. refuse: original outside MEDIA_ROOT
mksrc /tmp/j.mkv; mkout /tmp/j.mkv /tmp/j.out.mkv
exit_is "outside MEDIA_ROOT exits 20" 20 sh "$SWAP" /tmp/j.mkv /tmp/j.out.mkv
rm -f /tmp/j.mkv /tmp/j.out.mkv

# 12. usage
exit_is "no args exits 2" 2 sh "$SWAP"

rm -rf "$T" "$TRASH_DIR/run-$$"
[ "$fail" -eq 0 ] && echo "ALL PASSED" || { echo "SOME FAILED"; exit 1; }
```

(Case 10 does not assert the trash path; the exit code plus later `rm -rf` cover it. Case 11 makes `/tmp` fixtures with `MEDIA_ROOT` still `/Media/.tdarr-test`, so the script must refuse.)

- [ ] **Step 4: Write the script**

Replace `kubernetes/apps/media/tdarr/app/scripts/tdarr-swap.sh`:

```sh
#!/bin/sh
# Verify a Tdarr encode, then swap it in and park the original in the trash.
#
#   tdarr-swap.sh <original> <output>
#
# Exit: 0 swapped | 10 verify failed, nothing changed | 20 swap refused or
#       failed, original restored | 2 usage.
# See design/decisions/tdarr.md. Every path is quoted: library names contain
# spaces and quotes.
set -u

FFMPEG="${FFMPEG:-ffmpeg}"
FFPROBE="${FFPROBE:-ffprobe}"
MEDIA_ROOT="${MEDIA_ROOT:-/Media}"
TRASH_DIR="${TRASH_DIR:-$MEDIA_ROOT/.tdarr-trash}"
DURATION_TOLERANCE="${DURATION_TOLERANCE:-1}"

say() { printf 'swap: %s\n' "$*"; }
verify_fail() { say "VERIFY FAILED: $*" >&2; exit 10; }
swap_fail() { say "SWAP REFUSED: $*" >&2; exit 20; }

[ $# -eq 2 ] || { echo "usage: $0 <original> <output>" >&2; exit 2; }
orig=$1
out=$2

[ -f "$orig" ] || swap_fail "original missing: $orig"
[ -f "$out" ] || verify_fail "output missing: $out"
[ -s "$out" ] || verify_fail "output is empty"

probe() { # probe <file> <select> <entries>
  "$FFPROBE" -v error -select_streams "$2" -show_entries "$3" -of csv=p=0 -- "$1"
}

# --- verify ---------------------------------------------------------------
codec=$(probe "$out" v:0 stream=codec_name) || verify_fail "ffprobe failed on output"
[ "$codec" = "hevc" ] || verify_fail "video codec is '$codec', want hevc"

dur_o=$("$FFPROBE" -v error -show_entries format=duration -of csv=p=0 -- "$orig") || verify_fail "ffprobe failed on original"
dur_n=$("$FFPROBE" -v error -show_entries format=duration -of csv=p=0 -- "$out") || verify_fail "ffprobe failed on output"
awk -v a="$dur_o" -v b="$dur_n" -v t="$DURATION_TOLERANCE" \
  'BEGIN { d = a - b; if (d < 0) d = -d; exit !(d <= t) }' \
  || verify_fail "duration $dur_n s vs original $dur_o s (tolerance $DURATION_TOLERANCE s)"

for kind in a s; do
  n_o=$(probe "$orig" "$kind" stream=index | wc -l)
  n_n=$(probe "$out" "$kind" stream=index | wc -l)
  [ "$n_o" -eq "$n_n" ] || verify_fail "'$kind' stream count $n_n, original has $n_o"
  l_o=$(probe "$orig" "$kind" stream_tags=language | tr '\n' ',')
  l_n=$(probe "$out" "$kind" stream_tags=language | tr '\n' ',')
  [ "$l_o" = "$l_n" ] || verify_fail "'$kind' languages '$l_n', original '$l_o'"
done

errs=$("$FFMPEG" -v error -i "$out" -f null - 2>&1 </dev/null)
[ -z "$errs" ] || verify_fail "decode errors: $(printf '%s' "$errs" | head -3 | tr '\n' ' ')"

sz_o=$(stat -c %s "$orig")
sz_n=$(stat -c %s "$out")
[ "$sz_n" -lt "$sz_o" ] || verify_fail "output $sz_n B is not smaller than original $sz_o B"
say "verified: $sz_o -> $sz_n bytes"

# --- swap -----------------------------------------------------------------
case "$orig" in
  "$MEDIA_ROOT"/*) rel=${orig#"$MEDIA_ROOT"/} ;;
  *) swap_fail "original is not under $MEDIA_ROOT" ;;
esac
dest="${orig%.*}.mkv"
if [ "$dest" != "$orig" ] && [ -e "$dest" ]; then
  swap_fail "$dest already exists"
fi

trash="$TRASH_DIR/$rel"
[ -e "$trash" ] && trash="$trash.$(date +%s)"
mkdir -p -- "$(dirname -- "$trash")" || swap_fail "cannot create trash directory"

# Same filesystem for all three, or mv becomes a long copy with a window where
# the file is half-written.
dev_o=$(stat -c %d -- "$(dirname -- "$orig")")
dev_n=$(stat -c %d -- "$(dirname -- "$out")")
dev_t=$(stat -c %d -- "$(dirname -- "$trash")")
[ "$dev_o" = "$dev_n" ] && [ "$dev_o" = "$dev_t" ] || swap_fail "output, original and trash are not on one filesystem"

mv -- "$orig" "$trash" || swap_fail "could not move original to trash"
# mv keeps the original's mtime; the purge job ages trash by mtime.
touch -- "$trash"
if ! mv -- "$out" "$dest"; then
  mv -- "$trash" "$orig"
  swap_fail "could not move output into place; original restored"
fi
say "swapped: $dest (original kept at $trash)"
```
